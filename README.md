# AI Agents in Practice: Companion Code

*Companion code for the [AI Agents in Practice](https://aiinpracticehub.com/series/ai-agents/) series on
[AI in Practice Hub](https://aiinpracticehub.com/).*

This repo contains article-specific, runnable labs (such as `part6/`). Examples are
deterministic and require no API keys.

## Parts
| Part | Folder | Topic |
|------|--------|-------|
| 6 | `part6/` | Building the Production Agent Loop: a deterministic verify-before-commit production-loop scaffold |

## Note
Examples use a fictional company, TechNova. TechNova is not real; all data, orders, and
policies are made up for teaching.
